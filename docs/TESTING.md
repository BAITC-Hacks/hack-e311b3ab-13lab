# Проверка текущего MVP

Проверено 23 сентября 2026 года. Это промежуточный рабочий коммит, не заявление о полном выполнении всех требований хакатона.

## Автоматические проверки

`python -m unittest discover -s tests -v` в `backend/`: 42 теста успешно, 1 пропущен без переменных PostgreSQL / MinIO.

Покрыты вход, сессии и их отзыв, блокировка перебора паролей, матрица ролей, сокрытие чужих совещаний, утверждение и возврат на доработку, статусы поручений исполнителями, журнал действий, управление пользователями, PDF и архив утверждённых копий, миграция старой SQLite-базы, согласие на обработку, лимит/формат/пустая загрузка, конфликт версий, DOCX и Markdown, проверка цитат, дубликаты и неоднозначные сроки. Это не нагрузочные тесты и не оценка качества моделей.

`tests.test_integration` с PostgreSQL 16 и MinIO в Docker: полный сценарий успешно. `docker compose up --build` проверен: три сервиса стартуют, таблицы создаются в PostgreSQL, bucket в MinIO, вход и создание пользователя работают. Обработка аудио внутри этой сборки не запускалась, чтобы не отправлять тестовые данные на сервер моделей.

Frontend: `npm run typecheck`, `npm run lint`, `npm test` (13 тестов: форматирование сроков, клиент API и отзыв сессии, вход, права в карточке поручения) и `npm run build` успешно. Весь стек из четырёх сервисов проверен в headless Chrome на отдельной копии с тестовыми данными: вход, список, проверка черновика, утверждение, «Мои поручения» исполнителя, пользователи, журнал и мобильная ширина 390 px без ошибок консоли и нарушений CSP.

## Реальный self-hosted сервис

`GET /v1/models` вернул HTTP 200 и модели `qwen`, `qazgramma`, `auto`, `til-asr`, `til-tts`. Обе предоставленные аудиозаписи прошли распознавание с timestamps и извлечение поручений. Ключи, исходное аудио и результаты находятся вне Git.

| Прогон | Время | Сегменты | Поручения | Условия |
| --- | --- | --- | --- | --- |
| Совещание 1, первый | 32,6 с | 47 | 9 | До второго прохода проверки и строгого расчёта дат |
| Совещание 2, первый | 23,4 с | 32 | 7 | До второго прохода проверки и строгого расчёта дат |
| Совещание 1, повтор | 54,4 с | 47 | 10 | Со вторым проходом; до последних уточнений парсера дат |

После этих прогонов исправлены отдельные словесные формы дат, очистка ошибки при успешном завершении и инструкция LLM не рассчитывать даты самостоятельно. Последний вариант полностью проверен unit/API тестами, но ещё не повторён на обоих аудиофайлах. Время зависит от сервера; указанные значения не являются гарантией производительности.

Обнаружены ошибки ASR в именах, топонимах и сроках. Второй проход вернул пропущенное поручение, но не устранил все ошибки исполнителей. Исходные PDF не передавались модели. Совпадение количества поручений с эталоном не доказывает правильности результата; precision/recall, WER и DER не измерены. Дата 2026-09-23 в прогонах — тестовый якорь, а не подтверждённая дата исходных встреч.

## Интерфейс и экспорт

Приложение запускалось локально на 127.0.0.1:8000. В браузере проверены страница загрузки и отображение обработанного второго совещания: саммари, поручения, исходные цитаты, timestamps, предупреждения и аудиоплеер. Полный интерактивный сценарий правок/скачивания и desktop-layout пока не пройдены. DOCX проверен структурно через python-docx; визуальная проверка печатного оформления ещё не выполнена.
