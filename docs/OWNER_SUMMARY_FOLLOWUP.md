# Исполнители и стабильность саммари

Проверено 23 сентября 2026 года после коммита MVP `77dda03`.

## Изменения

- Неизвестный исполнитель может быть восстановлен только из целой исходной реплики, входящей в цитату поручения: явное обращение «имя + отчество» и ограниченный набор побудительных форм. Вопрос «можно добавить?», повреждённое имя и несколько адресатов не подходят. Это узкая эвристика для русской речи, не универсальное определение адресата. Восстановленное имя остаётся `owner_uncertain=true`, с вопросом для прослушивания; связь с учётной записью не устанавливается.
- Проверка цитат саммари теперь выполняется перед подсчётом покрытия. Корректирующий запрос принимается только если сохраняет все ранее покрытые числовые фрагменты, добавляет новые и не увеличивает число ошибок прямых цитат. При равном или худшем результате сохраняется первая версия. Это защита внутри одного запуска, не гарантия одинакового текста между запусками или правильности пересказа.
- Под саммари доступен раскрываемый список исходных числовых фрагментов с переходом к реплике. Он не дописывает цитаты в саммари ради повышения счётчика. Счётчик по-прежнему означает дословное покрытие целых фрагментов, а не смысловую точность чисел.

Сохранённые ASR и pyannote-результаты из `backend/data/release-checked/` обработаны без изменения исходников. Новые результаты находятся в игнорируемом Git каталоге `backend/data/owner-summary-review/`. Поручения повторно не извлекались: проверена новая эвристика и выполнены живые запросы саммари к `qorytyn-qwen3.6-27b` через настроенный H200-туннель. Это не новый полный прогон аудио.

Нурлан Сагатович восстановлен для инструктажа из прямого обращения и «вот и проводите, ждем от вас». Это кандидат из ASR, не подтверждённая человеком личность. Для синхронизации бюджета и совещания с подрядчиками ФИО не подставлялись из эталонного DOCX или близлежащего упоминания. Нужны прослушивание и подтверждение адресата в панели проверки источника.

Саммари всё ещё требует проверки. Низкий показатель дословного покрытия не означает отсутствие чисел: модель использует сокращённые цитаты и пересказ. В новом саммари №1 дополнительно замечено описание срока аудита как уточняемого, хотя карточка хранит согласованный срок. Защита от регрессии числовых фрагментов такую смысловую ошибку не ловит. Полная стабильность и исправление всех проблем не заявляются; старые саммари и ручные правки не заменены новыми результатами оценки.
